## 5. HOW TO SET IT UP (Step by Step)

**Step 1 — Subscribe to a store:**
eBay Seller Hub → Account → Subscriptions → Store subscription
→ Choose "Starter" ($4.95/mo) to start

**Step 2 — Set store name & description:**
eBay Seller Hub → Store → Manage Store → Edit Store
→ Paste store name + description from above

**Step 3 — Upload the banner:**
→ Open `ebay-store-banner.html` in Chrome at 100% zoom
→ Screenshot the banner (1200×270px area)
→ Upload at: Store → Store Image → Banner

**Step 4 — Add categories:**
→ Store → Store Categories → Add the 8 categories above

**Step 5 — Set your store URL:**
→ Your store URL will be: **ebay.com/str/tingtong**
